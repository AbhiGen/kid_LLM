# Kids' Nutrition LLM

This project is an explainable and interpretable LLM focused on kids' nutrition balance. It uses a pretrained conversational model, fine-tuned on a custom dataset, to provide safe and evidence-backed nutrition guidance.

## Features

-   **Conversational AI:** A chatbot that can answer questions about kids' nutrition.
-   **Explainability:** LIME for local model interpretability and confidence scores for each recommendation.
-   **Meal Planner:** A tool to generate meal plans based on a child's age, gender, allergies, and dietary restrictions.
-   **Nutrition Facts:** A searchable database of nutrition information.
-   **Safety Features:** Auto-checks for choking hazards, allergens, and age-appropriateness.

## Getting Started

### Prerequisites

-   Python 3.7+
-   Pip

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/kids-nutrition-llm.git
    cd kids-nutrition-llm
    ```
2.  Install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

### Running the Application

You can run the application in two modes: `full` and `demo`.

**Full Mode**

In full mode, the application will first generate the dataset, then fine-tune the model, and finally run the Gradio web UI. This will take a significant amount of time and computational resources.

```bash
python setup.py --mode full
```

**Demo Mode**

In demo mode, the application will run the Gradio web UI with a pre-trained `microsoft/DialoGPT-small` model. This is a much faster way to try out the application, but the model's responses will not be as accurate or tailored to the nutrition domain.

```bash
python setup.py --mode demo
```

## Architecture

The project is structured as follows:

-   `data/`: Contains the dataset generation script and the generated dataset.
-   `src/`: Contains the fine-tuning script and the explainability module.
-   `deployment/`: Contains the Gradio web deployment script.
-   `models/`: Contains the fine-tuned model.
-   `notebooks/`: Contains Jupyter notebooks for experimentation and analysis.
-   `run_demo.py`: A script to run the application in demo mode.
-   `setup.py`: A script to set up and run the application.
-   `requirements.txt`: A list of the required Python packages.

## Dataset

The dataset is generated by the `data/create_nutrition_dataset.py` script. It consists of 2000+ question-answer pairs covering a wide range of topics, including:

-   Age groups (toddlers to teens)
-   Meals (breakfast, lunch, dinner, snacks)
-   Allergies
-   Picky eating
-   Nutrition facts
-   Food safety
